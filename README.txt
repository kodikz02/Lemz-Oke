LEMZ-OKE STARTER PROTOTYPE 0.1
Open index.html in a desktop browser to preview the TV interface.

Included: neon karaoke layout, scrolling Up Next marquee, sample-song search, demo queue, basic queue controls.
Not yet included: actual MIDI/SoundFont playback, synced lyrics, USB media access on Tizen, Android remote pairing, Tizen packaging/installation.

This is a first visual prototype, not a working karaoke player yet. Google Fonts are optional and load only when internet is available.
